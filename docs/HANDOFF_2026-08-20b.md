## ⛔ 6. TRAPS — THE 2026-08-20b SET, each one paid for today

1. ⛔ **NEVER WRITE A REGEX THROUGH A SHELL HEREDOC. Sixth occurrence.** It happened inside the
   audit that closes G27: the escape became a literal newline and left an unterminated string.
   The pattern now lives at module level with a self-test, typed with the Edit tool.
2. ⛔ **A VALUE VOCABULARY LIES, AND IT LIED FIVE TIMES TODAY.** `state_code` on FRPP is the
   numeric FIPS `'18'` and `state_name` is uppercase, so `'IN'` and `'Indiana'` both matched
   nothing. `notice_class` on WARN is UPPER-CASE. `nearestBus` filters on a **lower-case**
   direction, so `"Withdrawal"` returns null — which renders as an honest-looking "no bus within
   25 miles". The roads tables use `geom`, not `geog`. `territoryAt` returns `utility`, not `name`.
3. ⛔ **THE DROUGHT MONITOR'S CATEGORIES ARE CUMULATIVE.** D0 means "D0 **or worse**", so
   `none + d0` is exactly 100 on every row. Summing d1+d2+d3+d4 reported one week as "91.5% at
   moderate drought or worse"; the real figure is d1 alone, **50.2%**. Caught only because 91.5%
   looked implausible against a series showing 97% clear in August.
4. ⛔ **AN IN-PLACE REPAIR THAT READS ITS OWN OUTPUT IS NOT IDEMPOTENT.** The substation repair
   rewrites its own table, so a second run would preserve whatever the first wrote — including
   anything a later rule now rejects. It discards its own derived values before recomputing, or
   the RE-SCRAPE COMMAND in its registry row is a lie.
5. ⛔ **A BUILD THAT APPENDS TO A PAYLOAD IT DOES NOT OWN WILL DOUBLE ITSELF.**
   `build_gas_facilities.py` took compressor 24 → 48 features and storage 22 → 44 the moment it
   was re-run. Valid GeoJSON, no error, every count overstated exactly 2×.
6. ⛔ **TWO CHANGES THAT ARE EACH FINE CAN BE FATAL TOGETHER — AGAIN.** Removing the `L-frpp`
   checkbox from the HTML while `CONTEXT_LAYERS` still named it made `$(box).addEventListener`
   throw during boot, before the map was built, so the page rendered nothing and the cause was
   nowhere near the symptom. Every other registry loop in `app.js` already guarded; that one did not.
7. ⚠ **A KEY IN THE WRONG PAYLOAD RENDERS EMPTY FOREVER, TWICE.** `audit_frontend.py` caught
   market reading from `wired` and grid reading from `wired2`. The rule is now written down: a key
   goes in the payload that the page rendering it already loads.
8. ⚠ **`PARTITION BY` a FLOAT64 is rejected outright**, and an `ArrayQueryParameter` with an
   inline `STRUCT<…>` type string is too. Use a string key; use parallel arrays zipped by offset.
9. ⚠ **`ST_UNION_AGG` over 92 county polygons, referenced as a scalar subquery, dies at 123% of
   the query memory limit.** Use a spatial JOIN — BigQuery can index it, and it hands back the
   county as a bonus.
10. ⚠ **A STATISTIC TRUE OF 98% OF THE CORPUS TELLS A SITER NOTHING.** The first (e) measure —
    "total acres of everything that touches" — was true of 521,312 of 532,693 parcels. Replaced
    with slivers, same-character land and the single largest neighbour.
