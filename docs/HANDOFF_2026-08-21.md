## ⛔ 4. INSTRUMENT FAILURES — the most useful section in this file

**In every case the instrument was wrong before the code was.**

1. ⛔ **A HARDCODED VERDICT IS NOT A PROBE.** `audit_backlog_truth.py` reported G53 as OPEN for two
   sessions after the filters shipped, because its G53 branch printed `"OPEN"` beside a mention
   count it never tested. A verdict that cannot change is a memory. Fixed to read the artefact.
2. ⛔ **AN AUDIT REGISTERED BUT NOT DISPATCHED RUNS AND REPORTS NOTHING.** Both new checkpoint
   audits matched their pattern, stored their result and fell off the end of an `if/elif` chain in
   silence; the checkpoint printed eight audits while ten had run. There is now an `else` that
   fails loudly.
3. ⛔ **A JOIN ON THE WRONG KEY.** `parcel_key` is the STATE parcel number; `parcel_id` is the
   county's dashed form. Joining them reported "99.0% of candidates carry no class code" against a
   column measured 97.8% populated.
4. ⛔ **`re.split` WITH A TWO-GROUP REGEX WROTE GARBAGE INTO EIGHT PAGES** — `</script>scriptscript`.
   The markup stayed well-formed, so **no audit could see it**; it was caught by reading the page.
5. ⛔ **A REGEX CANNOT PARSE THIS CODEBASE'S RENDERED TEXT.** A template nested inside another
   template's `${...}` is the shape nearly every rendered string uses. The spelling fixer missed six
   real occurrences and the audit then reported **ZERO** and looked clean. Both now use
   `scripts/js_prose.py`, a real lexer, proven on an 11-case injected regression.
6. ⛔ **TWO AUDITS COUNTING DIFFERENT POPULATIONS DISAGREE FOREVER.** After G122 the payload held
   23,766 flagged parcels and the warehouse said 23,795, and the honesty audit shouted that one was
   lying. Neither was.
7. ⛔ **A UNIT ERROR.** PJM publishes RTEP `cost_estimate` **already in $M**; dividing by 1e6 made a
   fully populated column read "not published".
8. ⛔ **MM/DD/YYYY IS NOT ISO, AND BOTH SIT IN ONE COLUMN.** PJM ships `2/19/2030`, MISO ships
   `2028-12-31`; `slice(0,4)` printed "2/19" as a year.
9. ⚠ **A PINNED LITERAL TURNS A MEASUREMENT INTO A CONSTANT.** `audit_handoff_docs.py` asserted
   `ribbon == 184` and failed the moment G122 correctly changed it to 25.
