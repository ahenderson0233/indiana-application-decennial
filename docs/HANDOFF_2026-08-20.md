## ⭐ 8. THE MAP NOW BOOTS HEADLESS — a limitation the docs called permanent

Every handoff since 2026-08-17 says *"the map does not boot headless, verify by calling handler
functions directly"*. True, but the cause is narrower and fixable: the pane is **hidden**, Chrome
**pauses requestAnimationFrame** in a hidden document, and MapLibre applies an inline style inside
a rAF callback — so `Style._load` never runs, `sourceCaches` stays empty, `load` never fires, and
the whole `map.on("load")` boot chain silently never executes.

`scripts/boot_map_harness.js` patches rAF to a timer and re-triggers the style load. Paste it into
the page console and `await bootMapHarness()`. Every front-end verification this session used it.
⛔ It is a TEST HARNESS, not a shim — never loaded by a page, and there is no defect in `app.js`.
⛔ It must never call `setStyle` twice; a sticky `window.__mapHarnessBooted` guard enforces that
after an early version wiped every layer while `state.loaded` still held 44,240 parcels.
