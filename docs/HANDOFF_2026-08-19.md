## 6. ⛔ SIX MISTAKES I MADE TODAY — every one caught by a check, none by reading

Recorded because each is a rule this project already had, and I broke it anyway.

1. **An exporter read `energy` directly.** My G48 patch put the DC→county spatial join inside
   `export_grid_sentiment.py`; the checkpoint failed within one run. Fixed the documented way — the
   join moved to `scripts/build_dc_county_counts.py`, because **builds may read `energy`, exports
   may not**, or the app cannot be rebuilt without the platform dataset.
2. **The exporter silently un-clipped G43** — grid went 9,020 features back to 10,659. Same shape
   as the IOCS defect above it, so it got the same treatment: the exporter now re-runs the clip
   itself and asserts. Both self-heals fire on the next run.
3. **A cross-product join invented coverage.** G69's first run linked every table a script mentions
   to every payload it writes and claimed `in_sites` — the 3.55M-parcel spine — was exposed by
   `L-terr`, the utility-territory checkbox. Coverage read 82 instead of 38.
4. **Four probes guessed column names** — `geog` (it is `geom`), `asset_class` (`substation_type`),
   `saleDate` (`auctionDate`), and a D4 query against a table where D4 has no rows, which returned
   "0 undated of 0" and read as DONE. **Rule 14, four times in one session.**
5. **I wrote regexes through shell heredocs three times** and one reached disk mangled. The rule
   says use the Write tool. It is right.
6. **I used backticks in `git commit -m`** and the shell ate the message. Use `-F`.

⭐ **The meta-lesson, and the one worth carrying:** every single one was caught by an automated
check or by measuring the data rather than reading the log. **Not one was caught by me looking at
my own work.** Build the check.
