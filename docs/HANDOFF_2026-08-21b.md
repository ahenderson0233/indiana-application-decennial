## ⛔ 5. INSTRUMENT FAILURES — the most useful section, and there were many

**In every case the instrument was wrong before the code was.**

1. ⛔ **`reached > held` ON D21, TWICE.** An impossible number is a statement about the instrument.
   South Bend continuous enforcement emits D21, not D5_vacant_board_order; and
   `in_si_indy_code_widened` emits SIX signals and was missing from the corpus map entirely. Fixed
   by asking the artefact which `source_block` produced the parcels — not by re-reading names.
2. ⛔ **A COLUMN AUDIT THAT PASSED ON A SERVICE ROOT.** It probed layer 0, so our 456 columns met
   their 79 and passed. Evansville FORECLOSURES is **twelve yearly layers** carrying 15–207 fields
   each; the honest denominator is their union (440).
3. ⛔ **A RE-SCRAPE REHEARSAL THAT MANUFACTURED WORK.** It reported `+149,719` on Evansville
   permits. That layer holds **all** building permits; the loader takes
   `USER_Project_Activity LIKE 'BUILDING WRECKING%'`, which returns **4,190 live against 4,190
   held**. Comparing a filtered table to an unfiltered endpoint is a category error.
4. ⛔ **AN HTML DIFF THAT INVENTED EIGHT FINDINGS.** Comparing raw HTML against decoded database
   text made `CICOA Aging &amp; In-Home Solutions` and `Snyder’s-Lance` look unheld. I reported the
   WARN PDF gap as 10, then 11; unescaping both sides left **three**.
5. ⛔ **AN AUDIT THAT SAMPLED A SPARSE FIELD.** My own Part B read 400 rows and declared the
   screener carried no intent signal — the export **omits a key when its value is falsy**, so
   `intent_signals` sits on 38 of 51,048 rows. It also did not know the exports rename
   `has_si_signal` → `has_signal`.
6. ⛔ **`re.I` CANCELLED A CASE-SENSITIVE GUARD.** The street pattern required each word to start
   uppercase, and the ignore-case flag silently defeated it, so `Plant 63 located at 2275
   Bloomingdale Drive` parsed as the street `63 located at 2275 Bloomingdale Drive`.
7. ⛔ **A REFUSAL WINDOW THAT LOOKED FORWARD.** It reached into the next paragraph, found
   *"please contact … Human Resources"*, and **refused the real plant**. In a letter the
   disqualifying label always PRECEDES its address.
8. ⚠ **A THIRD PINNED LITERAL.** `flagged parcels == 23795` failed the moment G150 correctly moved
   it. Unpinned, like `ribbon == 184` and the rung tolerance before it.
