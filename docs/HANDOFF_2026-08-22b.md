its first run it also caught `in_si_funnel` **26 hours** stale, which nobody had noticed.

**③ THE "FEEDS A SIGNAL?" COLUMN WAS WRONG THREE TIMES IN ONE SESSION, AND IT IS THE G156
WORKLIST.** (a) Scanning three scripts for the clip name → false negatives, because most clips
reach the spine through a placement table. (b) Chain-following every builder → **false positives**,
because the spine names refused tables in **COMMENTS** — *the better the refusals are documented,
the more tables look wired*. (c) Stripping comments → false negatives again, because in this
codebase **the SQL lives inside triple-quoted strings**. ⛔ **A source-text scan cannot answer this
question.** It is DECLARED lineage now, and every declaration is verified against the warehouse —
the named table must hold rows and the named signal must admit parcels, or the generator exits.

classified `too_few` by a `corpus_rows <= 10` threshold. Its two rows are **GSA federal land
auctions** carrying a published lat/lon, an auction date and a sale price. An agency auctioning
land is the least ambiguous seller there is. **Rarity was the reason to admit it.** Branch deleted.

**⑤ A SIGNAL CAN BE CORRECTLY BUILT AND STILL BE MISLABELLED — AND THE LABEL IS THE DEFECT.**
`D17_commercial_eviction` shipped at county grain for one build: 92 counties, **278,645 filings**.

and EV is overwhelmingly residential landlord-tenant. ⚠ **A recency window would not have saved
it** — narrowing the years makes the number smaller and no more commercial. Withdrawn from the
table, the payload key and the popup rows in one change. **G165.**
