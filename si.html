D16 candidate — structure fires that would actually move an owner to sell

A signal only counts when it plausibly produces seller intent. A contained kitchen fire does not, and a house is not a hyperscale site. So the raw file is narrowed three times: to structure fires, to non-residential property, and to material loss. Each step is shown, so the discard is auditable rather than a number appearing from nowhere.
